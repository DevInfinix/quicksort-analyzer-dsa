# Quicksort Records

A C program that manages student records and sorts them using the Quicksort algorithm with configurable sorting field, order, and pivot strategy.

## What It Does

- Add and display student records (ID, name, marks)
- Sort by ID, name, or marks
- Sort in ascending or descending order
- Choose pivot strategy: first, last, or middle element
- Track comparisons, swaps, partitions, and recursive calls

## How to Compile

```bash
gcc quicksort_records.c -o quicksort_records
./quicksort_records
```

## Requirements

- GCC or any standard C compiler
